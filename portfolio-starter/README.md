# Portfolio Starter

This directory contains a minimal Vite + React + Tailwind CSS starter for a personal portfolio.

Contents
- package.json: dev/start scripts and dependencies
- vite.config.js: Vite + React plugin
- tailwind.config.js, postcss.config.js
- src/: React entry, app, components, pages, and CSS
- public/index.html: Vite entry HTML

How to run
1. cd portfolio-starter
2. npm install
3. npm run dev

Notes
- This scaffold was added to a subdirectory to avoid changing existing project files in the repository root.
- Update the contact email and project list in src/pages/Projects.jsx and src/pages/Contact.jsx.
